# WHAT IS REAL? 视觉与交互系统

## 设计依据

优先级为上传Word逐屏具体规范、其内嵌参考图、《Blade Runner 2049》视觉语言，再到项目内 UI UX Pro Max Skill 与专业实现判断。Skill 是辅助工具，不能替代、覆盖或改写已确定的内容与设计。

本项目读取 `.agents/skills/ui-ux-pro-max/SKILL.md` 并使用现有离线查询；没有重新安装Skill、调用图片API或为Skill引入服务。复核命令：

```bash
python .agents/skills/ui-ux-pro-max/scripts/search.py 'HUD immersive cinematic' --domain style --max-results 3
```

本地 `styles.csv` 返回 HUD / Sci-Fi FUI、Parallax Storytelling、Cyberpunk UI。采纳细线刻度、技术标记、独立图层、电影式构图，以及对比度、键盘、可见焦点、减少动态效果要求。通用HUD推荐的高饱和青蓝、全站暗底、滚动视差和打字机建议均需服从Word逐屏要求；本项目采用Word锁定的章节配色和限定动画场景。

## 字体和层级

Word建议 Space Grotesk / Inter 作为英文叙事字体、IBM Plex Mono作为系统字体、思源黑体 / Noto Sans CJK SC作为中文字体。本项目本地托管 Space Grotesk 与 IBM Plex Mono；使用Latin子集及所需字重，避免远程字体请求和不必要字符集。中文遵循 `Noto Sans CJK SC`、`Microsoft YaHei` 和系统无衬线字体回退，显示形态随设备可用字体变化。

英文在前，中文紧随同一文本块下方。中文通过字号与层级区分，手机不小于12px。字幕工作台中的中文字幕是研究与操作对象，给予足够字号和视觉权重。屏幕16只呈现英文电影对白，不提前透露中文选项。Word中仅有中文的基准线说明按原文呈现，不自行补写英文译文。

## 布局与组件

桌面参考1440×900，主体约7%侧边距，宽屏保留左右构图、双档案、镜像人物、字幕选择与预览并置。手机参考390×844，重排为垂直内容，允许自然滚动，输入控件与底部导航留安全区；字幕解释改为可关闭的底部抽屉。

叙事、选项、行动按钮、章节导航与中英文文本块复用组件；基准线、字幕台和结局有独立交互组件。视觉效果独立于叙事状态，背景层不捕获核心操作，装饰结构不作为假数据或额外正文。

## 动效边界

- 封面四词在同一位置短促顺序故障闪现，再黑场并显示正式标题。闪词没有中文；提供跳过及减少动态效果。
- 打字机仅用于电影基准线04–05逐题问答，可立即跳过，中文跟随英文整体出现。
- 其余叙事完整呈现或轻微整段淡入，不逐字打印。
- 扫描、机械反馈和选中脉冲响应操作；纹理与线条保持低对比，避免正文被遮挡。
- 测试冷白、档案琥珀、投影粉紫与纸白结尾使用不同材质和运动节奏；结局仅保留微小动作。
- `prefers-reduced-motion` 与手动减少动态效果共同控制装饰运动；声音默认关闭。

## 无障碍与验收约束

所有选择均可通过键盘及触控操作，焦点有可见描边；主要触控区域至少44px。选中状态同时有边框/符号/状态属性。读者决定页面推进时间，所有AI立场进入同样三个情境；不设置人性分数、虚假通过率或正确答案。

构建、状态测试与浏览器检查分别验证不同问题。最终报告应只列实际执行的视口和检查范围，不能由技术兼容目标推断跨浏览器全部通过。

## 内容锁定与素材

全部32屏按源稿顺序保留。缺失的21不补写；用户明确确认两版30连续呈现，使用内部ID `30a`、`30b`，保留原文及各自可选输入。参考图仅作局部主体素材，与原创SVG/CSS界面层组合；原始来源和裁切记录见 [ASSETS.md](ASSETS.md)。
