# 验证记录

日期：2026-10-26。执行环境：Linux、Node 24.19.0、预装 Chromium；浏览器自动化使用预装 Python Playwright。以下是实际执行结果，不代表所有浏览器或实体设备的兼容性认证。

## 构建与状态测试

- `npm run build`：TypeScript 检查与 Vite 生产构建通过。
- `npm test`：8 项状态／内容测试通过，包括损坏会话恢复、原判断与重新判断分离、3+4+1 次基准线计数及上限、四种独立字幕组合、自定义空白校验、无预设用户数据、32 屏顺序与两段结尾原文。
- 源文件检查：`src/`、`public/` 未发现原调查数据、受访者内容、词云、心理／人性分数、通过率或数据上传请求；用户状态使用当前浏览器的 `sessionStorage`。

## 实际浏览器体验路径

1440×900 和 390×844 均完成以下完整流程；视觉／布局修正后再次执行了完整手机流程。

1. 开场、身份、首次记忆判断、测试说明；CELLS 3 次、INTERLINKED 4 次、WITHIN 1 次。
2. 三道原创题、记忆档案、EVENT／OWNERSHIP 判断、可关闭翻译注释、K／Joi 视角与纯英文对白。
3. 字幕未完成时禁止确认；Joi B＋K A 的实时预览与后续页面、理由多选及自由文本、注释抽屉。
4. 虚拟陪伴立场与三个情境；第二情境必须先点击 REVEAL DESIGN 才显示选项。
5. 四重真实、K 的选择、设计者揭示、个人回顾；真实选择、组合字幕及理由全部传递。
6. 重新判断保留最初判断；复制回顾；实际下载 PNG 回顾卡；第一结尾输入后进入第二结尾，第二结尾可不回答并进入结束页。
7. 参考来源弹窗、重看字幕、四种 A／B 组合；两行独立自定义；空白自定义无法确认；修改字幕使确认状态失效；刷新保留当前会话选择；研究模式跳转不改写已有选择。

以上完整流程均通过，未出现未捕获 JavaScript 异常。两种目标视口的全部 32 屏均检查了页面横向尺寸，页面 `scrollWidth` 等于视口宽度；主内容中的可见中文标注未出现小于 12px 的情况。内部四重真实卡片使用允许的横向滚动；装饰图形受页面容器裁切，不计为正文溢出。

## 额外交互与可访问性检查

- 正常动画模式实际观察到 Real? → Virtual? → Feeling? → Love?，同时最多只有一个闪词；标题在词序列后出现，轮询观测约 2.7 秒。
- 基准线英文逐字显示，SKIP TYPING 能立即完成当前句。
- 键盘 Space 可选择选项，焦点具有 2px 可见描边；浏览器返回保持字幕选择。
- 未答题的研究模式回顾保持未答状态，不生成字幕或用户判断。
- SOUND 与手动减少动画开关可切换；重启清除体验选择。静音下同样可以完成流程。
- 手机注释使用原生模态对话框；Tab 未进入底层页面控件，Escape 关闭并返回触发按钮。浏览器允许焦点短暂进入浏览器工具栏。
- 手机字幕页的可见按钮和输入控件点击区域均不小于 44×44px。
- 844×390 横屏字幕页没有页面横向溢出。
- 720×450 的全部 32 屏通过横向重排检查，可作为 1440×900 在 200% 缩放下的有效视口近似检查。
