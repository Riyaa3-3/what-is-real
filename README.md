# WHAT IS REAL? / 何以为“真”？

根据用户上传的《何以为真_网站逐屏视觉与交互脚本_V1.2双端定稿.docx》开发的沉浸式互动叙事网站。React 19、TypeScript 5.9、Vite 7；桌面与手机共享全部内容和选择状态，采用分别适配的布局。

文档中的32张屏幕卡均按原顺序保留：00–20、22–29、30a、30b、31。源稿没有第21屏；用户已确认两版第30屏依次保留，文案原样呈现。

## 本地运行

需要 Node.js 22.12 或更高版本及 npm。

```bash
npm ci
npm run dev
```

打开终端显示的地址。生成和预览发布版本：

```bash
npm run build
npm run preview
```

构建产物在 `dist/`。Vite 使用相对资源路径 `base: './'`，可部署到 GitHub Pages 仓库子路径或其他静态托管目录。

## 使用与验证

首次体验按顺序推进；章节菜单中的研究展示模式可快速跳转，保留已有选择。封面四词故障闪屏约 5.55 秒，可跳过；减少动态效果遵循系统设置，也可手动切换。背景音乐默认开启、音量 25%，电影原声对白独立控制；因浏览器自动播放限制，首次点击后可能才开始有声播放。

```bash
npm test
npm run build
```

自动测试覆盖状态恢复、基准线3+4+1计数与回访上限、四种字幕组合、自定义输入、独立结局输入及完整屏幕顺序。CI 对提交和 PR 执行上述测试与构建，并保留30天可下载的 `what-is-real-build` 静态产物。浏览器验收应另行检查1440×900、390×844、键盘操作、200%文字缩放、减少动态效果、字幕编辑至最终回顾的数据传递；单元测试不能替代这些检查。具体实测结果以本次交付报告为准。

目标浏览器为较新版本 Chrome、Edge、Firefox 与 Safari（建议 Safari 17.4+）；手机建议较新版本 iOS Safari 或 Android Chrome。代码使用原生 dialog、动态视口单位、CSS color-mix、Web Audio、Canvas 和 Clipboard API。复制在浏览器禁止剪贴板时提供可手动选择的文本；导出在本机生成。目标浏览器范围不代表已经完成全部浏览器的实际测试。

## 会话与隐私

用户选择、理由、自定义字幕和两次开放回答存于当前标签页的 `sessionStorage`；不需要账号，不上传服务端，不加入分析追踪。刷新同一标签页可恢复；重新开始清空体验记录。序章最初判断与回顾时重新判断分别保留。没有原12人调查模块、统计数据、受访者观点、人性评分或心理结论。

英文字体通过本地构建资源提供，中文使用系统字体回退。没有图片API、第三方图片服务或外部字体请求。访客首次使用九轨电影原声及背景音乐时，可在 AUDIO 菜单导入聊天中提供的音频包；音频包只存于当前浏览器，不上传服务端。若仓库后续直接托管 `public/audio/` 下的九个 MP3，则访客无须导入。浏览器自动播放限制不影响无声完成体验。

已验收 V2（包括章节过渡、电流动态、音频 3＋4＋1 映射、25% 默认背景音乐和较慢的封面闪屏）由 `main` 分支作为正式网站版本发布。

访问：https://riyaa3-3.github.io/what-is-real/

`.github/workflows/ci.yml` 在 push 和 pull request 时执行单元测试与构建。正式 GitHub Pages 工作流 `.github/workflows/deploy-pages.yml` 在 `main` 更新后自动构建、测试并发布 `dist/` 至正式网站根路径，也允许手动从 `main` 运行。

音频源文件的托管与首次导入步骤见 [音频使用说明](docs/AUDIO-V2.md)。**当前 GitHub 仓库尚未托管九段 MP3 二进制文件；尚需首次浏览器导入音频包。** 这一点不得与网站源代码的音频播放支持混为一谈。

影片原声的公开使用由素材权利提供方确认。请在最终发布时核实素材授权范围及其他原始视觉素材的使用权限。
